# 🤖 Telegram Bot Setup Instructions

## Step 1: Create Telegram Bot

1. Open Telegram and search for **@BotFather**
2. Send `/newbot` command
3. Give your bot a name (e.g., "Prediction Marketplace Bot")
4. Give your bot a username (must end with 'bot', e.g., "my_prediction_bot")
5. **BotFather will give you a TOKEN** - Copy this token!
   - Example: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

## Step 2: Get Your Chat ID

### Method 1 (Easy):
1. Search for **@userinfobot** on Telegram
2. Start chat with it
3. It will send you your **Chat ID**
4. Copy the number (e.g., `123456789`)

### Method 2 (Manual):
1. Send a message to your bot (the one you just created)
2. Open this URL in browser (replace YOUR_BOT_TOKEN):
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```
3. Look for `"chat":{"id":123456789` - that's your chat ID

## Step 3: Update the HTML File

Open `prediction-marketplace.html` and find these lines (near the top of the `<script>` section):

```javascript
const TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE';  // Replace this
const TELEGRAM_CHAT_ID = 'YOUR_CHAT_ID_HERE';      // Replace this
```

Replace with your actual values:

```javascript
const TELEGRAM_BOT_TOKEN = '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz';  // Your bot token
const TELEGRAM_CHAT_ID = '123456789';  // Your chat ID
```

## Step 4: Test It!

1. Open the website
2. Select a team (India or Pakistan)
3. Enter bet amount
4. Click "PLACE BET NOW"
5. **You'll get a Telegram message immediately!** 📱

The message will show:
- Bet ID
- Team selected
- Amount
- Potential winnings
- Timestamp

6. After user enters UTR and clicks "Confirm Payment"
7. **You'll get another Telegram message with the UTR!** ✅

## 🔒 Security Notes

- **Keep your Bot Token SECRET!** Don't share it publicly
- Only you (with your Chat ID) will receive notifications
- Users cannot see your bot token or chat ID

## ⚠️ Important CORS Note

If you're testing locally (file:// protocol), Telegram API might not work due to CORS.

**Solutions:**
1. Use a simple HTTP server (recommended):
   ```bash
   python -m http.server 8000
   ```
   Then open: http://localhost:8000/prediction-marketplace.html

2. Or upload to any web hosting (GitHub Pages, Netlify, Vercel, etc.)
